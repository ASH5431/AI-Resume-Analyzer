# AI Resume Analyzer 🤖

An AI-powered web application that analyzes resumes and extracts skills using NLP, then compares them with job requirements to generate a score and suggest improvements.

## 🚀 Features
- Upload resume (PDF)
- Extract skills automatically
- Resume scoring system
- Missing skill suggestions
- Error handling for invalid PDFs

## 🛠 Tech Stack
- Python
- Flask
- spaCy
- scikit-learn
- pdfplumber

## ▶️ How to Run
```bash
pip install -r requirements.txt
python app.py
